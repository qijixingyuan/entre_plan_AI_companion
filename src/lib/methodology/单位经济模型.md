# 单位经济模型（Unit Economics）

> 这是系统当前**最缺的一层**：之前跑机 4 个月的结果是种子脚本写死的 hint，学生无法自己算。
> 本模型让跑机**真结算**——把每个学生的假设接进算式，事件冲击直接改算式变量。
> 公式基于管理会计「边际贡献 / 盈亏平衡」标准算法，并对齐国创赛「盈亏平衡点为财务必查项」。

---

## 一、核心公式

```
单客月毛利  = 月营收 ÷ 付费学员数 − 单客月变动成本
月营收      = 付费学员数 × (客单价 ÷ 期月数)
盈亏平衡学员数 = 月固定成本 ÷ 单客月毛利
盈亏平衡营收  = 月固定成本 ÷ 毛利率
```

| 变量 | 含义 | 学生须填什么 |
|---|---|---|
| 客单价 | 每期 / 每单收费 | 真实报价（参考本地竞品） |
| 期月数 | 一次付费覆盖的月数 | 课程周期 |
| 付费学员数 | 同时在训人数 | 可观测量级 |
| 单客月变动成本 | 教练课时 + 场地分摊 + 耗材，均到每人每月 | 逐项列出 |
| 月固定成本 | 房租 + 基础运营 + 管理，不随人数变 | 逐项列出 |
| 毛利率 | 毛利 ÷ 营收 | 自动算出 |

> **放行纪律**：`revenue` 节点放行前，学生必须能套此式给出「保本学员数」具体数字（DEV-GUIDE §11「缺的三样」第 1 条）。

## 二、长沙体育新城 · 中考体育培训 示例（可算）

| 项 | 数值 | 说明 |
|---|---|---|
| 客单价 | 2400 元 / 期 | 一期 12 次课，参考体新城商业机构报价 |
| 期月数 | 3 个月 | 一期约一学期 |
| 在训学员数 | 50 人 | 假定初始规模 |
| **月营收** | 50 × (2400 ÷ 3) = **40,000 元** | |
| 变动成本/月 | 教练 80×4×50=16,000 + 场地 2,000 + 耗材 500 = **18,500 元** | |
| **毛利** | 40,000 − 18,500 = **21,500 元** | |
| 单客月毛利 | 21,500 ÷ 50 = **430 元** | |
| 固定成本/月 | 房租 8,000 + 运营招生 4,000 + 管理 2,000 = **14,000 元** | |
| **净利** | 21,500 − 14,000 = **7,500 元** | |
| **盈亏平衡学员数** | 14,000 ÷ 430 ≈ **33 人** | 低于 33 人即亏 |

**结论（学生要自己算出来的一句话）**：在体育新城开中考体育培训班，同时在训 **33 人以上才不亏本**，50 人时月净利约 7500 元。

## 三、4 回合冲击如何接入算式

事件库四类（天气 → 政策 → 市场 → 经营）逐月打在**学生自己的假设变量**上：

| 回合 | 事件类型 | 改变的变量 | 教学意义 |
|---|---|---|---|
| 第 1 月 | 市场（获客成本涨） | 单客月变动成本 ↑ | 验证定价是否扛得住获客压力 |
| 第 2 月 | 天气（极端天气停课） | 有效期月数 ↓ → 月营收 ↓ | 验证到课率/退费假设 |
| 第 3 月 | 政策（预收款受限） | 现金流结构变（不与公式直接冲突，但影响存活） | 验证抗政策风险能力 |
| 第 4 月 | 经营（教练挖角） | 单客月变动成本 ↑ 或 交付能力 ↓ | 验证 `moat` 节点是否成立 |

> 每次冲击后，系统重新跑一遍 §一 公式，给出新的盈亏平衡学员数；学生须解释「为什么扛住了 / 为什么崩了」。

## 四、出处

- 精益画布「收入来源 / 成本结构」双格：Maurya, *Running Lean* (2010)
- 国创赛 2025 职教赛道：财务分析章 **盈亏平衡点为必查项**
- 边际贡献 / 盈亏平衡：管理会计标准算法（成本性态：变动 / 固定），非某单一作者原创，属通用管理常识
- 【待校准】长沙示例中的客单价 / 房租等**具体数字为教学演示假设**，教师应按体育新城真实行情替换为学生可取证的数；替换后即成为可验证的真假设。
